# Battleship Game

Author: Georgia Kalapotharakou

This is a battleship game written in C. The game creates a 15x15 board, places 4 ships horizontally or vertically randomly across the board, while ensuring none of these overlap, and places one bomb somewhere in the available board spaces randomly. The player is asked to guess row and column coordinates. Hits are marked with X, misses are marked with O, and the bomb is marked with Z. The player wins by sinking all four ships and loses if they hit the bomb.
